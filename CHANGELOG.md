# Changelog

## Version 1.0

- Displays the combined durability percentage of equipped items, or `N/A` when none have durability.
- Refreshes the display on world entry and when the inventory durability update event fires.
- Supports dragging an unlocked frame and locking it in place.
- Provides `/sds lock`, `/sds unlock`, and `/sds size <number>` commands.
- Saves frame position, lock state, and font size in the addon's saved variables.

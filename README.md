# SimpleDurabilityStatus

SimpleDurabilityStatus displays the current durability percentage of your equipped gear on screen. The display updates when durability changes and when you enter the world.

## Features

- Shows the combined durability percentage of equipped items.
- Updates automatically when equipment durability changes.
- Move the display by dragging it while unlocked.
- Saves the frame position, lock state, and font size between sessions.
- Shows `N/A` when no equipped item has durability.

## Installation

1. Download or clone this repository.
2. Place the `SimpleDurabilityStatus` folder in your World of Warcraft `_retail_/Interface/AddOns/` directory (or the matching AddOns directory for your game client).
3. Enable **SimpleDurabilityStatus** from the AddOns list at the character selection screen.

## Slash Commands

| Command | Description |
| --- | --- |
| `/sds unlock` | Unlock the display so you can drag it to a new position. |
| `/sds lock` | Lock the display in its current position. |
| `/sds size <number>` | Set the font size to a positive number. |
